refactor: one attendance screen instead of two

Attendance was reachable from two places with the same purpose and different
capabilities, which made the app feel broken rather than feature-rich:

- the schedule's session modal could mark statuses for any date, but had no
  WhatsApp report and a cramped list layout
- /attendance had the big tap cards and the WhatsApp report, but was hardcoded
  to today, so a forgotten session could never be filled in afterwards

Neither was a superset, so a coach had to learn which one to reach for. The
standalone page is the better interface for the common case -- marking a squad
at the door, one-handed, players queueing -- so it survives and gains the
missing capability instead.

- /attendance now has a session picker defaulting to today, covering any date
- the schedule links to /attendance?session=<id> for that session
- the schedule keeps a read-only "✓ present/squad" badge per row, so it can
  still answer "who turned up?" without becoming a second editor
- the WhatsApp report now dates itself from the selected session rather than
  from today, which was wrong as soon as a past session could be opened
- components/schedule/session-detail.tsx deleted

Data is unaffected: both screens always wrote to the same attendance rows, so
this only removes an interface.

The URL param is read with useSearchParams inside a Suspense boundary rather
than in an effect, so opening a past session does not flash today's screen
first.
