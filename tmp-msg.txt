fix: drop the identity before retyping id columns

The migration failed with:

  22023: identity column type must be smallint, integer, or bigint

Every id column was declared `generated by default as identity`, and Postgres
refuses to change the type of an identity column. The step to drop the identity
before widening to text was missing.

Also restores a uuid default on each id afterwards, so rows inserted from the
Supabase dashboard (rather than the app) still get an id.
